# 响应式全屏 UI

## 目标

- 页面内容随 Electron 窗口和浏览器视口宽度自然扩展。
- 全屏时不再受 `max-w-6xl` / `max-w-7xl` 限制而产生大面积两侧留白。
- 保留适量安全边距，避免内容紧贴窗口边缘。
- 课程配置和进度侧栏在宽屏下弹性增长，但保持合理上限。
- 课程列表与日志区域利用更高窗口的垂直空间。
- 小窗口下继续使用单列布局，不产生横向滚动。

## 验收

- 900px 宽窗口下布局可用且无横向滚动。
- 1920px 全屏下主内容明显扩展，左右空白仅为响应式页边距。
- 课程页与进度页侧栏宽度保持在可读范围。
- 前端生产构建通过。
