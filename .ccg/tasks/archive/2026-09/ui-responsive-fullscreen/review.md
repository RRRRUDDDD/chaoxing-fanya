# Review

## Checks

- `npm run build`（`web/`）通过。
- `git diff --check` 通过。
- 未修改后端接口、Electron 窗口尺寸或业务逻辑。

## Result

- 页面顶部与主内容统一使用流式 `.page-shell`，宽屏下不再被固定 `max-w-*` 限制。
- 课程页、进度页侧栏使用 `minmax()` 与 `clamp()`，在小窗口单列、大窗口弹性扩展。
- 登录卡片、课程列表和日志高度使用响应式限制，兼顾可读性与全屏空间利用。
- 根字号仅做小范围流式调整，并限制在 15–17px，避免浏览器缩放或超宽屏下文字失控。
